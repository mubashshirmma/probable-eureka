Key Concepts

6 Core Rules
N

Natural Numbers (N)

Counting

Positive integers starting from 1 with no upper limit.

{ 1, 2, 3, 4, ... }
W

Whole Numbers (W)

Zero Included

All natural numbers augmented with zero.

{ 0, 1, 2, 3, ... }
Z

Integers (Z)

Positive & Negative

Complete set of whole numbers along with their additive inverses.

{ ..., -2, -1, 0, 1, 2, ... }
Q

Rational Numbers

p / q Form

Expressible as p/q where p, q ∈ Z and q ≠ 0. Either terminating or repeating decimals.

Examples: 1/2, 0.75, 4 (-4/1), 0.333...
I

Irrational Numbers

Non-Repeating

Cannot be written in ratio format; decimals are non-terminating and non-recurring.

Examples: √2, π, √3, e
P

Prime Numbers

Exam Alert

Numbers strictly greater than 1 with exactly two distinct factors: 1 and the number itself.

{ 2, 3, 5, 7, 11, 13, 17, 19, ... }
lightbulb Crucial Fact: 2 is the ONLY even prime number!

Question / Definition sync

What is the only even prime number, and why?

Answer Revealed

2 is the only even prime number. Any higher even number is divisible by 2, giving it at least three factors (1, 2, and itself).
